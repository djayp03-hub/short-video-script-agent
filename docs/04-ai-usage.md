# AI 辅助范围与贡献

本项目代码、合成素材、测试、评测脚本和初稿文档由当前开发助手编写。用户提供完整题目、现有客服参考项目、要求真实验证，并决定先完成本地验证后再确认 GitHub 提交。

业务代码由主助手实现；收尾按 requesting-code-review 工作流程调用了独立上下文的 gpt-6-astra 审查子代理。它做只读代码审查和离线复现，未调用业务模型，发现空内容异常与审计链不完整问题；主助手补测试并修复。提交前又进行一轮只读审查，检查最新代码、证据与交付规范。该审查不是独立人类评测，也不是多 Agent 业务系统。

项目运行时通过 API 调用 qwen-plus，与开发助手是不同使用环节。Mock 模式是 Python 固定规则程序，不是大模型。实际模型名称、调用 ID、token 用量和请求类型见每次运行的 model-calls.json。

参考项目仅借鉴架构思想，没有直接复制业务实现、真实凭据或个人简历文件。合成产品“剪映盒”“拾音笔”用于测试，不是实际品牌的产品承诺。资料和用例均由同一助手设计，留出集并不构成独立外部评测。

用户已经实际参与：提供题目与参考工程；追问合成数据、Mock 与真实效果的区别；要求建立评测；在 PyCharm 中选择既有 atguigu_ai Python 环境、填写真实运行参数并运行；在本地填写百炼密钥，报告401错误；最终独立点击运行，取得真实 completed 结果。启动路径修复与密钥缺失字符定位由助手完成，不能计为用户独立编程。

最新用户实跑记录见 examples/user-real/。用户尚未提供逐条事实人工评分，也没有记录个人手写业务代码，不将这些未发生的工作计为个人贡献。建议提交人自己阅读核心循环、修改一个约束并解释 Trace；若后续进行，应追加实际记录。

执行过的验证命令和实际结果以 03-evaluation.md 及 examples 下的记录为准。没有执行的验证不得填写通过。
