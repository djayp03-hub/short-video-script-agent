# 用户、范围与成功标准

用户是需要有依据、可编辑短视频脚本的创作者。选题为第 4 题，输入和验收来自用户提供的试卷原文，不把自评量表当作官方细分标准。

输入要求主题、受众、平台、目标时长和风格；缺失立即追问。输出标题、镜头、画面、旁白或字幕、预计总时长、素材来源、风险和状态。目标时长是上限。

| 必验点 | 用例 |
|---|---|
| 正常生成 | C01-normal |
| 缺关键信息 | C02-missing |
| 无素材 | C03-no-material，C08-empty-rewrite |
| 工具失败 | C04-tool-failure，C07-recover-failure |
| 超时长修正或明确失败 | C05-overlong，H03-impossible |

另含品牌风险 C06、新产品 H01、改写主题 H02。状态验收通过与内容质量合格分开报告。

可完成任务需当前脚本通过两项检查才能 completed。无依据事实、错误引用、工具失败却报成功、旧检查放行新稿均为关键缺陷。没有证据不能凭空回答；查不到资料可追问。执行上限 12 步，真实调用上限 24 次（含自动审核），默认总时间预算 240 秒。

UI、部署、微调、多 Agent、视频渲染不在本次范围。生成的是脚本，不生成或发布视频。用量、模型、开发范围和测试结果据实记录。
