# 用户、范围与成功标准

用户是需要有依据、可编辑短视频脚本的创作者。选题为第 4 题，输入和验收来自用户提供的试卷原文，不把自评量表当作官方细分标准。

输入要求主题、受众、平台、目标时长和风格；缺失立即追问。输出标题、镜头、画面、旁白或字幕、预计总时长、素材来源、风险和状态。目标时长是上限。

| 必验点 | 用例 |
|---|---|
| 正常生成 | C01-normal |
| 缺关键信息 | C02-missing |
| 无素材 | C03-no-material，C08-empty-rewrite |
| 工具失败 | C04-tool-failure，C07-recover-failure |
| 超时长修正或明确失败 | C05-overlong，H03-impossible |

另含品牌风险 C06、新产品 H01、改写主题 H02。状态验收通过与内容质量合格分开报告。

可完成任务需当前脚本通过两项检查才能 completed。无依据事实、错误引用、工具失败却报成功、旧检查放行新稿均为关键缺陷。没有证据不能凭空回答；查不到资料可追问。执行上限 12 步，真实调用上限 24 次（含自动审核），默认总时间预算 240 秒。

首版以 CLI 完成必需交付；2026-10-30 增加仅本机使用的聊天 UI。部署、微调、多 Agent、视频渲染不在本次范围。生成的是脚本，不生成或发布视频。用量、模型、开发范围和测试结果据实记录。

## 多轮交互扩展

用户可以在聊天框逐轮补齐创作需求、补充产品事实、要求缩短或修改脚本。同产品且同主题可沿用上一版；换产品或主题重新开始。修改后的脚本必须重新检查，未改动旧稿不能冒充改稿成功。普通交流不生成新的完成结果；沿用旧结果时必须标明来源轮次。

真实模式由模型整理需求并决定是否启动任务；离线模式仅验证固定字段补全、工具流程与有限时长修正。素材仅作为用户提供的事实，未经外部核实。服务绑定本机，支持刷新恢复、下载脚本与本地记录，不提供公网部署和历史会话列表。聊天验收与界限见 [评估](03-evaluation.md) 和 [使用说明](07-chat-guide.md)。
